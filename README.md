# Dual Momentum (GEM) — a backtest built on free data

Replication of Gary Antonacci's **Global Equities Momentum**, 1971–2026, built
entirely from **freely available** data sources.

The accompanying paper is
[`research_paper/Petit_2026_Global_Equities_Momentum.tex`](research_paper/Petit_2026_Global_Equities_Momentum.tex).
Every figure and table in it is generated by the code in this repository; no
number is typed by hand.

## The rule

Each month, using only the information available at that date:

```
if  12-month return(US equity) > 12-month return(T-bills):   # absolute momentum
        hold US or non-US equity, whichever has the better   # relative momentum
        12-month return
else:
        hold US aggregate bonds
```

## Results (1971-01 → 2026-07, 667 months)

| | CAGR | Volatility | Sharpe | Max drawdown |
|---|---:|---:|---:|---:|
| **GEM** | **15.18%** | 12.91% | **0.83** | **−21.66%** |
| S&P 500 | 11.27% | 15.20% | 0.50 | −50.95% |

Annualised alpha 6.61% (t = 4.31, Newey–West standard errors), beta 0.57,
R² 0.45.

**Decomposition** — the two filters do not add up: absolute momentum alone
+77 bps, relative momentum alone +203 bps, the two together **+391 bps**.

**Allocation versus timing**: a static portfolio holding GEM's own average
allocation (46% US / 28% non-US / 25% bonds, rebalanced monthly) returns
10.03% — that is 124 bps *less* than the S&P 500. The asset basket is therefore
a handicap over this sample; all of the excess return comes from the timing.

**Main caveat**: the whole of the outperformance comes from 1971–2009
(+7.7 pt a year). Over 2010–2026 GEM loses 4.8 pt a year to the S&P 500.

## Data

Four monthly total-return index levels in USD, from December 1969. The
historical core comes from a redistributed CSV, extended to the present with
Yahoo Finance, MSCI's public index endpoint and the Kenneth French Data Library.

That core is a redistribution, not a primary source, so it is **audited against
nine independent references** — and the audit found a real defect (three T-bill
observations that had lost their leading digit, since repaired). See
[`data/VALIDATION.md`](data/VALIDATION.md) and
[`data/SEGMENTS.md`](data/SEGMENTS.md).

## Usage

```bash
pip install -r requirements.txt
python src/gem_backtest.py        # backtest, figures and tables — offline
```

**The dataset is versioned and frozen**: nothing to rebuild, nothing to
download. To check that it is intact, or to extend it with new months:

```bash
python src/build_dataset.py             # offline check against its fingerprint
python src/build_dataset.py --refresh   # adds ONLY the new months
python src/validate_dataset.py          # regenerates the data audit
```

See [`data/README.md`](data/README.md) for using the dataset on its own.

## Layout
